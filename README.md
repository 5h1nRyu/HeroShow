# HeroShow

一个用于展示“月度最佳选手”的 1280 × 720 响应式揭晓动画。

## 运行

项目不需要构建步骤。建议从仓库根目录启动本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作

- 页面默认以铺满浏览器可视区域的展示模式运行，并循环播放动画。
- 按下空格键进入播放控制模式，显示播放、暂停、重播、进度、倍速和浏览器全屏控件。
- 再次按下空格键返回展示模式，动画将从当前位置继续播放并恢复循环。
- 播放控制模式下可按 `R` 重播、按 `F` 切换浏览器全屏，也可用左右方向键微调进度。

空格键只用于切换展示模式与播放控制模式，不用于播放或暂停。
